Sobre o projeto

Arcanum é um catálogo de jogos feito para estudo de HTML, CSS, Bootstrap e JavaScript. Os dados ficam em uma lista no código e a página é montada dinamicamente.

Como usar

  • Clique em uma categoria para filtrar.
  • Use a busca e a ordenação para refinar a lista.
  • Toque no coração para favoritar.
  • Clique em “Detalhes” para ler a descrição completa.
