Sobre o projeto

Arcanum é um catálogo de jogos feito para que você possa explorar e organizar seus jogos favoritos de forma simples e intuitiva.

Como usar

  • Abra o catálogo para filtrar por categoria e buscar jogos.
  • Clique no coração de um card para favoritar.
  • Os favoritos aparecem nesta página inicial.
  • Clique na capa ou em “Detalhes” para ler mais.
  • Use o botão ☀ / ☾ no topo para trocar entre modo claro e escuro.
