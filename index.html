Sobre o projeto

Arcanum é um catálogo de jogos feito para explorar títulos e descobrir novas opções de forma simples e intuitiva.

Como usar

  • Abra o catálogo para filtrar por categoria e buscar jogos.
  • Clique no coração de um card no catálogo para salvar como favorito.
  • Clique na capa ou em “Detalhes” para ler mais.
  • Use o botão ☀ / ☾ no topo para trocar entre modo claro e escuro.
